  `GET /admin/console/{overview,tasks,users}`。
- **可等待工具**（P3 续跑）：`get_task` / `approve_task_plan` 支持 `wait_seconds`
  轮询 + 执行期 `tool_wait` keepalive，支持「建任务 → 等规划 → 确认规划」闭环。

  任务 FAILED 可 replan。

- **审计日志**（#25）：`audit_log` 表，凭据变更/计费变更留痕，`GET /admin/console/audit`。

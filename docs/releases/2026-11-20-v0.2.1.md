## 变更摘要（Issue #26 公开页 UI 打磨）

- **注册页文案随页签切换**：`Create account / 创建你的账号 / 注册以开始你的第一篇综述`；
  提交按钮从「注册并登录」改为「创建账号」（注册后要先验证邮箱，本来就没登录）。
- **`/register` 独立路由**：页签与地址栏双向同步，对外分享的注册链接不再落回
  `/login?redirect=/tasks`；已登录访问 `/login`、`/register` 都回任务列表。
- **重置密码页**补品牌页头与「返回登录」，重置成功后给「用新密码登录」。
- **文案空格**：修「你负责判断， 系统负责」——Vue 会把源码里跨行的文本节点压成一个空格。
  标题「让每一句论断，都…」源码里没有空格，巡检那条是 `innerText` 把 `<br>` 当换行造成的误判
  （E2E 用 `textContent` 断言已锁死）。
- **假链接**：左上角 Logo 改成首页链接；「证据可回溯」从 `text-primary` 假链接改成带图标的标签。
- **注册细节**：用户名/邮箱补占位提示；ALTCHA 保护文案统一成一处。
  踩坑：ALTCHA v3 的 `observedAttributes` 只有
  `auto/challenge/configuration/display/form/language/name/theme/type/workers`，
  **`hideFooter` 不在其中** —— 裸属性或直接赋同名 property 都无效，必须走
  `configuration='{"hideFooter":true}'`，否则 widget 页脚会多出一行「由 ALTCHA 保护」
  （这正是巡检看到的两种大小写）。

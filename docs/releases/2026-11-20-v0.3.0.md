## 变更摘要（Issue #27 定时重跑）

- **手动刷新**：任务详情页「再次检索新文献」→ 只取上次之后入库的文献（窗口回退
  7 天覆盖索引延迟），与既有 screening 快照 + 参考文献按 `DOI → source_id → 题名`
  多键去重，生成带 `[E#]` 的增量摘要并**复用 #25 的引用一致性闸门**；模型编号越界
  时回落为确定性清单（`citation_ok=false`），刷新不因此失败。
- **定时重跑**：`task_routine`（每任务 0..1 条）+ 进程内 asyncio tick（单 worker），
  `UPDATE ... WHERE next_run_at <= now` 原子认领 + `SKIP LOCKED`；周/月两种频率，
  月度夹到月末；停机期间错过的排期不补跑。
- **邮件汇报**：定时刷新有新增时复用 `EmailSender` 发摘要（`notified` 幂等），
  手动刷新不发（用户在页面上直接看）。
- **配额口径**：刷新**不扣篇数**（不生成新综述），token 用量记在 `task_refresh`；
  手动刷新 10 分钟冷却。
- **检索相关性**（验收中连修三次，见下）：`LiteratureSearch.fresh_only` 把窗口写进
  arXiv 检索式（`AND submittedDate:[...]`）并保持 relevance 排序；OpenAlex 用
  `from_publication_date` 过滤 + relevance 排序；再加一道**主题词过滤**
  （题名/摘要命中任一主题词才算相关），跑题的计为「与主题无关已过滤」并写进摘要首行。

## 验收中发现并修掉的问题

1. 只把排序改成「最新优先」→ RAG 评估主题刷出颈动脉超声、老年外语学习等 26 篇
   无关论文。改为「窗口进检索式 + 相关度排序」。
2. 改字段时漏改 OpenAlex，`'LiteratureSearch' object has no attribute 'sort_by'`
   → OpenAlex 每次刷新都失败（被 `MultiSource` 隔离成静默单源故障）。
3. arXiv 429/503：连续验收把节奏打满 → 429 归类为临时错误 + 全失败后等 20s 重试一次。
4. 窗口内仍有跑题论文 → 主题词过滤。

## 已知取舍

- 刷新**不计篇数**，只记 token：按篇收费等于同一篇综述收两次钱；若后续要按次计费，
  在 `start_refresh` 里补一次 `plan_service.check_and_consume_review` 即可。
- 邮件只发「有新增」的期次：0 新增时不发，避免每周一封空邮件。
- 主题词过滤是词面匹配，同义改写（如「检索增强」vs「RAG」）靠主题词表同时包含
  中英文词来覆盖；再严格就需要向量相似度，成本另算。

## 1. 冻结接口（实现方不得改名/改语义）

### 1.1 数据库：`CitationStyle`

```python
# app/db/models/citation_style.py
class CitationStyle(Base):
    __tablename__ = "citation_style"

    id: UUID                       # 主键
    user_id: UUID | None           # NULL = 系统预置（全局可见）；非 NULL = 该用户私有
    style_id: str                  # 归一后的唯一标识（≤64），与 CSL 文件名一致
    title: str                     # 人类可读名（≤256）
    numbering: str                 # citation-number / none
    ordering: str                  # citation-order / author-date
    default_locale: str            # 默认 en-US
    filename: str                  # 磁盘文件名（≤128，服务端生成，不信任客户端）
    content_sha256: str            # 内容指纹（64），用于去重与完整性
    size_bytes: int                # 文件大小（≤ MAX_STYLE_BYTES）
    created_at / updated_at
```

约束：
- `UniqueConstraint("user_id", "style_id")`：同一用户内 `style_id` 唯一；
  系统预置 `user_id IS NULL`，用 `UniqueConstraint("style_id", "user_id")` 无法约束 NULL，
  故另建**部分唯一索引**（`user_id IS NULL` 上 `style_id` 唯一）。
- 预置样式**不落库**（由 `StyleRegistry` 静态提供），DB 只存用户上传的；
  列表 API 合并两者并标注 `source: "preset" | "custom"`。

### 1.2 存储布局

```
{artifact_root 同级}/csl_styles/{user_id}/{style_id}.csl
```
- 目录按用户隔离；文件名由服务端按 `style_id` 生成（**不接受客户端文件名**，防路径穿越）。
- `style_id` 由服务端从 CSL `<info><id>` 派生并规范化（小写、非字母数字→`-`），
  与用户输入冲突时加后缀 `-2`、`-3`。

### 1.3 API（全部 Bearer 鉴权，owner-scoped，跨用户 404）

```
GET    /api/v1/citation-styles              列出（预置 + 当前用户自定义）
POST   /api/v1/citation-styles              上传 .csl（multipart file）
DELETE /api/v1/citation-styles/{style_id}   删除当前用户的自定义样式
GET    /api/v1/tasks/{task_id}/references.bib   下载 BibTeX
GET    /api/v1/tasks/{task_id}/references.ris   下载 RIS
```

响应模型（`app/schemas/citation_style.py`）：

```python
class CitationStyleOut(BaseModel):
    style_id: str
    title: str
    numbering: Literal["citation-number", "none"]
    ordering: Literal["citation-order", "author-date"]
    default_locale: str
    source: Literal["preset", "custom"]
    is_default: bool = False

class CitationStyleList(BaseModel):
    styles: list[CitationStyleOut]
    default_style_id: str
```

上传响应 `201` + `CitationStyleOut`；准入失败 → **400**，`detail` 含逐条 reasons
（沿用 M1 `StyleRejected.reasons`，**绝不静默接受**）。

### 1.4 渲染侧接线

- `StyleRegistry` 增加可选参数 `custom_dir: Path | None`：
  `list_styles()` 仍只返回预置（协议不变），**新增** `list_all(custom_styles)` 由 API 层合并；
  渲染器只需 `resolve()` + `meta()` + `get()` 能找到自定义样式文件。
- 自定义样式参与渲染时，`StyleRegistry` 必须能解析到它：
  新增 `register_custom(style_id, path)` / `unregister_custom(style_id)`（进程内注册，幂等）。
  渲染路径对自定义样式与预置样式**完全一致**（同样走 `validate_csl_file` 准入）。

### 1.5 前端

- `src/api/citation-styles.ts`：`listCitationStyles()` / `uploadCitationStyle(file)` / `deleteCitationStyle(styleId)`
- `src/components/tasks/TaskCreateForm.vue`：`citation_style` 由硬编码两项改为**下拉**（预置 + 自定义）
- `src/views/StyleView.vue` + 路由 `/styles`：上传、列表、删除
- 类型定义加入 `src/api/types.ts`

## 6. 常用命令（含两个必踩的坑）

### 本地门禁（**逐个跑**，不要串起来）

```powershell
cd 'E:\Multi-agent collaborative automation task assistant\backend'
.\.venv\Scripts\python.exe -m black app tests evaluation scripts
.\.venv\Scripts\python.exe -m ruff check --fix app tests evaluation scripts
.\.venv\Scripts\python.exe -m mypy app evaluation --no-incremental
.\.venv\Scripts\python.exe -m pytest tests -q --cov=app --cov-fail-under=80 --basetemp="$env:TEMP\pytest-dsh"
```

### 坑 1：GitHub 直连不通，必须显式走代理

```powershell
git -c http.proxy=http://127.0.0.1:7894 -c https.proxy=http://127.0.0.1:7894 push backup main
$env:HTTPS_PROXY='http://127.0.0.1:7894'   # gh 需要这个
gh run list --limit 3
```

代理端口从注册表读：`Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings'`。

### 坑 2：ssh 一行命令里带 glob/括号必被远端 zsh 拒绝

```powershell
# ❌ 会挂：ssh ylin@10.0.10.2 'git fetch ~/maa.bundle "+refs/heads/*:refs/remotes/win/*"'
# ✅ 写脚本再执行
scp "$env:TEMP\xxx.sh" ylin@10.0.10.2:~/x.sh; ssh ylin@10.0.10.2 'bash ~/x.sh; rm -f ~/x.sh'
```

### 部署

```powershell
$b = Join-Path $env:TEMP 'maa.bundle'
git bundle create $b --all
scp $b ylin@10.0.10.2:~/maa.bundle
# 服务器上：bash ~/df.sh   （若 ff 失败，用 git reset --hard win/main 强制对齐）
```

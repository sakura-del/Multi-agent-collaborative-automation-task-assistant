## 7. 必须知道的九个坑（都真实踩过）

1. **compose 项目目录**：`-f deploy/ecs/docker-compose.yml` 只读 `deploy/ecs/.env`，
   根 `.env` 靠软链暴露。
2. **根 compose 的 `environment` 是白名单**：`.env` 配了但没白名单，容器里读不到（CORS、STORAGE 都踩过）。
3. **CRLF 陷阱**：`sed 's/\r$//'` 会把行尾字母 `r` 一起吃掉（`veripaper`→`veipape`）。
   正确做法：base64 传脚本，或 `tr -d '\r'`。
4. **SSH 长会话约 60 秒被对端断开**：长任务一律 `nohup ... &`，再用短命令轮询。
5. **PowerShell 会吃掉引号与反斜杠**：复杂命令写成 `.sh` 再执行；本机 `curl` 是
   `Invoke-WebRequest` 别名，要用 `curl.exe`。
6. **Cloudflare 令牌有客户端 IP 白名单**：业务端点统一返回 403 `Authentication error`，
   只有 `GET /accounts/{id}` 会明说 `Cannot use the access token from location: <IP>`。
7. **Pages 必须用 wrangler 部署**：手写 REST 直传会“API 成功、日志成功、整站 500”。
8. **pg_dump 必须 17**：源库是 PG 17.11；且 PG17 的 dump 自带 `CREATE SCHEMA public;`，
   恢复时要过滤，否则 `already exists` 中断整个恢复。
9. **pgvector 在 `extensions` schema**：`<=>` 运算符不在默认 `search_path` 里，
   需要 `ALTER DATABASE veripaper SET search_path TO "$user", public, extensions;`。

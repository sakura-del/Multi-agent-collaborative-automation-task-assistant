## 加固：fail2ban（2026-11-12 已安装）

**版本**：1.0.2；**服务**：`enabled` + `active`

配置 `/etc/fail2ban/jail.local`：

```ini
[DEFAULT]
backend = auto
bantime = 1h
findtime = 10m
maxretry = 5
ignoreip = 127.0.0.1/8 ::1 13.125.5.87

[sshd]
enabled = true
port = 22
mode = aggressive
```

要点：

- **封禁实际走 nftables**（`table inet f2b-table` + `set addr-set-sshd`），
  不是 iptables——Ubuntu 24.04 上 fail2ban 自动选 `nftables` action。
  排查时若 `iptables -L f2b-sshd` 显示"无此链"不代表失效，
  应查 `nft list ruleset | grep <ip>`。
- 白名单只放**本机 + 当前运维出口**（`13.125.5.87`）。
  **刻意不放 Cloudflare / Fastly 网段**——它们是公共代理出口，加白等于给攻击者开口子。
- 封禁 1 小时自动过期，即使误封也能自愈；手动解封：
  `fail2ban-client set sshd unbanip <IP>`。

**验证**（用 RFC 5737 保留地址，不误伤真实主机）：

| 步骤 | 结果 |
| --- | --- |
| `banip 203.0.113.99` | nft set 中出现该地址 |
| `unbanip 203.0.113.99` | 从 set 移除，残留 0 |
| 服务状态 | `enabled` / `active` |
| 阈值行为 | 10 分钟内 1 次失败 → 不封（阈值 5），符合预期 |

## 严重缺陷修复：时间线渲染成空白卡（fd2bcc8，用户截图反馈）

- 根因 1：四个子组件模板用了 `<Motion>` 但**漏 import Motion**——
  Vue 按未知元素渲染，MotionValue 全部失效：x/scale 丢失（8 卡叠中央）、
  白色遮罩 opacity 恒 1 盖住整卡 → 看起来是一张空白卡。
- 根因 2：cables 把 MotionValue 绑到原生 `<line>` 属性 → `[object Object]`。
  motion-v 的 Motion 不接管 SVG 标签，改用 useMotionValueEvent → 响应式数字。
- 诊断方法：测试机 Playwright（需 Node20，已装 ~/node20 + chromium v1248）
  打线上演示页 evaluate getComputedStyle；脚本 ~/vp-test/frontend/tl-debug*.mjs。
- 教训：**新 UI 上线前必须真浏览器截图验收**，单测断言不到 transform。

## Resend 邮件接入（用户要求 fetch resend.com/setup.md 并执行）

- 背景：注册验证/密码重置邮件此前只写日志不真发（email.sender=logging）。Resend 补上此缺口，
  应用代码**零改动**（SmtpEmailSender 标准 STARTTLS）。
- 落地：域名 `mail.veripaper.me`（东京区域）→ Cloudflare API 加 4 条子域 DNS（DKIM TXT/
  bounce MX/SPF TXT/rbounce CNAME，零冲突，不碰根域）→ `resend domains verify` 约 1 分钟全 verified。
- 密钥：`sending_access` + 限定单域名（泄露不能读域名/发其它域）。CLI `login --web` OAuth
  存 Windows 凭据管理器。服务器 .env 8 个 EMAIL__ 键（600），后端 up -d 重启重读 lru_cache 单例。
- **坑 1**：`docker exec vp-backend python -` 少 `-i` → stdin 没接上静默退出无输出。
- **坑 2**：`cfat_` 前缀是账户级 Cloudflare 令牌，`/user/tokens/verify` 必 401（文档 §2.2 有记录），
  要用 `/accounts/{id}/tokens/verify`。
- 验证：SmtpEmailSender send()=True（发给 yanglin125210@gmail.com）；业务端到端
  POST /auth/register 201 + 日志 email_sent=true（yanglin125210+resend-test@gmail.com，Gmail + 别名）。
- runbook `ecs-deployment.md` §21（DNS 表、运维命令、送达率注意：海外出口发 QQ/163 可能进垃圾箱）。


## 邮箱验证门禁（用户截图实测：没验证邮箱就进了系统）

- 根因三层：前端 register 自动登录；后端 login 不查 email_verified_at；重发端点要登录态（死锁）。
- 修复：403 EMAIL_NOT_VERIFIED 门禁（EMAIL__REQUIRE_VERIFIED_LOGIN，默认关——SMTP 未配置不阻塞，
  生产 true）；未验证不计入 M-3 失败退避；重发端点免登录按邮箱+恒定响应+60s 冷却（查 email_token）；
  迁移 b8e4f2a6c9d1 回填存量用户（CURRENT_TIMESTAMP，now() 是 PG 专用 SQLite 会炸）；
  前端注册成功引导卡 + 登录 403 提示重发 + normalizeError 保留 code/details。
- **坑（§5 #62）**：端点 get_settings() vs 测试 patch 模块级 settings——CI 全量 cache_clear 后对象分叉，
  单跑绿全量红。统一读模块级 settings。

## 注册人机验证：ALTCHA 自托管（用户要求先调研）

- 调研结论：Turnstile **官方不支持大陆**（大陆探针 60s 加载不完）→ 排除；reCAPTCHA/hCaptcha 同理排除。
  用户选 ALTCHA（MIT 自托管 PoW），范围仅注册入口。
- 后端 `app/core/captcha.py`：无状态 HMAC 挑战 + `data.ip` 指纹（复用限流 IP 解析）+
  Redis `SET NX EX` 一次性 nonce（故障 fail-open）；`GET /auth/captcha/challenge` 免登录；
  配置 `CAPTCHA__*` 默认关，生产已开。注册校验在最前（被挡不耗 DB/发信）。
- 前端：`altcha@3.6.0` + `altcha/i18n/zh-cn`；启动探测 enabled 才渲染；按钮未验证时 disabled；
  **CSP 加 `worker-src 'self' blob:`**（Worker 用 Blob URL）。
- **坑 §5 #63**：v3 属性是 `challenge`（v2 叫 `challengeurl`）。传错的后果是 widget 不报错、
  回退请求**当前页面** `/login` → 报 "invalid content-type text/html"。判据：抓网络看有没有请求 /login。
- **坑 §5 #64**：altcha 只 pip install 没写 pyproject → CI 收集阶段 exit 2（无 FAILED 行）。
- 生产实测：真实浏览器 PoW **1.2s** 解完 → 注册 201；无 payload 422 missing；重放 422 nonce_used；
  探针账号已清。回退方式：`CAPTCHA__ENABLED=false` + 重启（20s）。
